# Prior art and provenance

Dated 14 July 2026, at the start of the Assembly Code cohort (grant term 13 July – 5 October 2026, grantee Johan Gace).

This repository is a fresh, from-specification build. The following assets existed before the grant term began, are separately owned, and are **not** part of this project or its AGPL-3.0 release:

1. **The Wyld Way "Nature Class / Rewyld for Schools" prototype** (`Wyld-Way/nature-class`, deployed at schools.rewyld.earth) — a pre-existing proof-of-concept owned by Wyld Way Corp, itself derived from the Rewyld web application. This repository is built fresh; the prototype serves as read-only reference, and interaction patterns such as the timestamp-derived timer and phase resume are re-implemented here rather than copied. Named material contributed from the prototype — from a single presentational fragment up to a whole page or a body of curriculum content — is contributed by Wyld Way Corp under the authority of its founder, relicensed (code AGPL-3.0, curriculum content CC-BY-SA-4.0), and recorded row by row in `PORT-LOG.md` in this repository. A release audit before the end-of-program AGPL publication verifies the boundary. Rewyld-platform code (payments, administration, account infrastructure, brand assets), the prototype's data model, and its runner state machine never enter this repository.
2. **Pre-existing curriculum work**, including the ReWyld 35-day curriculum (December 2025) and related session drafts owned by Wyld Way Corp / Johan Gace. The starter pack authored for this repository during the grant term (the sessions written new against schema v1, and the tips authored fresh) is released under CC-BY-SA-4.0. Distinct from it, a teaching year adapted from the prototype's `practiceData.ts` — the four-season curriculum and the never-served spring drafts — was contributed by Wyld Way Corp, relicensed CC-BY-SA-4.0, and is recorded in `PORT-LOG.md`; it is ported content, not authored fresh here.
3. **Pointmoon** (Apache-2.0), a separate nature-intelligence service. This project consumes it strictly as an external HTTP API; no Pointmoon source is vendored here.
4. **The Rewyld application, backend, and design system** — pre-existing Wyld Way Corp IP, out of scope.

Behavioral overlap with the prototype (e.g., a facilitator-led session flow) is intentional and re-implemented from written specification. Code in this repository is authored during the grant term and licensed under AGPL-3.0 (see LICENSE). Curriculum content in `packs/` is licensed under CC-BY-SA-4.0 unless stated otherwise.
